# Dynamic Form Builder (React + Express + MongoDB)

## Overview
This project is a full-stack dynamic form builder with analytics.

## Tech Stack
- React (Frontend)
- Express.js (Backend)
- MongoDB (Database)

## Features

### 1. Dynamic Form Builder
- Create forms with text, number, select fields
- Dynamic schema stored in MongoDB

### 2. Form Submission
- Public form rendering
- Stores responses as key-value pairs

### 3. Analytics Engine
- Total submissions
- Select field distribution
- Average numeric values

### 4. Response Viewer
- Table format display of submissions
